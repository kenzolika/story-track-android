# Сторис-трек (Android)

Нативная оболочка для [story-track.kenzolika.workers.dev](https://story-track.kenzolika.workers.dev):
делишься треком из Яндекс Музыки → получаешь карточку для сторис → «В сторис» → Instagram.

- Ловит «Поделиться» (`ACTION_SEND text/plain`) и передаёт текст в страницу через `?text=`.
- Страница открывается во встроенном WebView, все темы и логика живут на сервере.
- Мост `window.Android`: `shareImage(dataUrl, name)` — системное «Поделиться» с картинкой,
  `saveImage(dataUrl, name)` — сохранение в галерею (`Pictures/Сторис-трек`).

## Сборка
GitHub Actions собирает подписанный APK на каждый пуш в `main`
и публикует его в **Releases**. Ключ подписи лежит в репозитории (он приватный),
поэтому новые версии ставятся поверх старых.
